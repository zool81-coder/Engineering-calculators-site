\## О проекте

Проект содержит набор простых веб‑калькуляторов для расчётов, полезных при проектировании и моделировании.



\## Структура проекта

\- `index.html` — главная страница

\- `css/` — стили

\- `js/` — скрипты

\- `powerm3/` — калькулятор мощности

\- `resistor/` — расчёт резисторов
